# Portofoliu — Țîgîrlaș Andrei

Primul meu site real: pagină statică de portofoliu cu Vite vanilla (HTML, CSS și JavaScript simplu).

Hero, Despre mine, Skill-uri și unelte, Proiecte, Contact.

npm install
npm run dev

Build de producție:

```bash
npm run build
```
